# دعيدر فلو — خطة الإصدار 0.1.0
المستودع الأصلي فارغ. هذا إصدار تجريبي لمتجر عام، وليس إقرارًا بجاهزية البيع.
1. SQLite وmigrations، مبالغ بالقروش وكميات بألف وحدة، متوسط تكلفة متحرك ومعاملات ذرية ومنع تكرار.
2. مدير بعد التفعيل، موظفون وصلاحيات وArgon2id وحدود محاولات وتغيير كلمة مؤقتة.
3. موصل هب وOpenAPI ومحاكي منفصل، توقيع Ed25519 وربط جهاز وتجديد موقّع.
4. منتجات وعبوات وأطراف، شراء، وردية، بيع متعدد الدفع ومرتجع وجرد وتقارير.
5. Electron وReact عربي/إنجليزي، adapter للطباعة ونسخ SQLite واستعادة.
6. اختبارات المسار وبناء NSIS وتوثيق القبول وحدود الخادم والأجهزة.
الوحدات المستقبلية مسجلة وغير متاحة. لا نشر سحابي أو دفع؛ تحديث تلقائي ومزامنة يحتاجان خدمة موثوقة.
