آخر تحقق محلي: 17 أكتوبر2026، Windows10 x64. المنتج تجريبي، وليس جاهزًا للبيع.

TypeScript وbuild واختبارات SQLite/قواعد العمل وElectron: نتائج التشغيل الفعلية مذكورة أدناه. اختبارات النواة تشمل8 مجموعات مستقلة ومجموعة تأكيدات لكل رحلة. راجع tests/journey.test.ts وtests/electron-smoke.cjs.

## ما يحتاج قبولًا قبل البيع
- بوابة هب فعلية: owner login/اشتراك/تسعير/اعتماد أدمن/device credential ونقل جهاز واستعادة المدير الوحيد. المتوفر عقد مقترح وموصل ومحاكي.
- سياسة ساعة موثوقة تشمل تقديم الساعة، وتجربةDPAPI على حسابWindows آخر، وتجربة انقطاع ونقل جهاز حقيقي.
- طابعة80مم وتعريفها والعربية، وإلغاء الطباعة وإعادة الطباعة الفعلية؛ طابعة58مم غير منفذة.
- تثبيت وترقية وإزالة على جهازWindows نظيف إضافي واختبار أحجام بيانات واقعية.
- واجهة تعرض أحدث300 مستند و500 دفعة؛ لا paging أوبحث أرشيف شامل بعد. التصدير الكامل لا يفقد الأقدم.
- وحدة أساسية وعبوة واحدة لكل منتج، استيرادJSON فقط. PIN واستعادة المدير الوحيد والمزامنة والتحديث الآلي والسحابة غير منفذة.
- الوحدات المتخصصة مسجلة فقط. لا GL ولا صافي ربح أو دفع إلكتروني متكامل.
- ميزات security لا تمنع مدير نظام محلي من تعديل البرنامج أو نسخ بياناته. نسخة التجربة تسمح بمحاكي ومفاتيح تحقق تطوير، ولا تستخدم للإنتاج.
## التغليف والتبعيات
Windows NSIS x64، أيقونة مشتقة بتكبير أصل دعيدر دون اختراع شعار. التوقيع Authenticode: NotSigned. ملفات المثبت خارجGit. حقوق المكونات فيTHIRD-PARTY-NOTICES وLICENSES.chromium.html المصاحب لـElectron.
npm audit عند تثبيت التبعيات:0 تنبيهات، inventory التبعيات لاGPL/AGPL/UNKNOWN في metadata؛ مراجعة إشعاراتChromium المرفقة مطلوبة قبل التوزيع التجاري.
## تشغيل الاختبارات
npm run typecheck ثمnpm test ثمnpm run build. لا اختبارات تستخدم بيانات عملاء. اختبارElectron يستخدم test-results/electron-userdata، ويتطلب تشغيلnpm run dev:hub وضبطDAIDAR_DEV_HUB=1 وDAIDAR_SMOKE=1 ثمnpm start؛ راجعelectron-smoke.json ولقطاتPNG فيtest-results.

## نتيجة اختبار المثبت الفعلي
نجح على هذا الجهاز: تثبيت NSIS صامت في مجلد اختبار، بدء التطبيق المثبت ووصول React إلى bootstrap عبر IPC، إزالة البرنامج، وبقاء قاعدة بيانات العميل خارج مجلد التثبيت. المخطط2 والتوقيع NotSigned. النتيجة الخام في validation/installer-smoke.json. الجهاز الإضافي النظيف والطابعة ما زالا مطلوبين. فحص app.asar وجد859 مدخلًا دون ملفات .env أو SQLite أو مفاتيح خاصة.

اختبار الاستعادة يشمل الآن قاعدة تثبيت مستقلة ومعرف جهاز ورخصة موقعة مختلفين داخل الاختبار، ويتحقق من بقاء رخصة التثبيت المستقبِل بعد استعادة بيانات المتجر. هذا ليس اختبار جهاز Windows مادي آخر. بصمة المثبت في validation/SHA256SUMS.txt.
