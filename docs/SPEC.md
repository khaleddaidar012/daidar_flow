# المواصفات والسياسات
Electron main تملك التخزين والخدمات؛ React لا تملك SQL أو Node أو الملفات. IPC بأوامر Zod وsenderFrame موثوق. sandbox وcontextIsolation مفعّلان وnodeIntegration معطل. لا محتوى بعيد في التطبيق.
منشأة/فرع/مخزن/كاشير واحد. البيع أوفلاين بعد التفعيل. كلمة هب لا تصل للتطبيق. رمز polling مؤقت بالذاكرة؛ ختم الوقت عبر safeStorage؛ لا تشغيل إنتاج عند غياب التخزين الآمن.
الأموال بالقروش والكميات بألف وحدة. تحويل عشري نصي وBigInt وتقريب نصف لأعلى. قيمة مخزون بالقروش ومتوسط متحرك. تصريف الكمية كاملة يسحب القيمة المتبقية. snapshots للأسعار والتكلفة. مرتجع بسعر وتكلفة المستند الأصلي مع توزيع تراكمي للتقريب. الخصم يوزع تناسبيًا. لا مخزون سالب. المستندات المعتمدة لا تعدل؛ التصحيح بمرتجع.
مثال: 12 قطعة بـ120 جنيه؛ بيع 2 بـ30: تكلفة20 وربح10. شراء10 بـ200 بعد البيع: 20 قطعة بقيمة300 ومتوسط15. بيع2 بـ40: تكلفة30 وربح10. كرتونة12 عاملها12000 والقطعة1000.
الرخصة موقعة Ed25519 مرتبطة بالتثبيت والاشتراك وتتضمن الوحدات والتواريخ ونسخة وkid. الخادم مصدر السعر والمدة؛ إصدار أحدث فقط وإعادة نفسه idempotent. آخر وقت موثوق لا يرجع مع ساعة الجهاز؛ انحراف الساعة يظهر تنبيه. offlineUntil حد موثق، graceSeconds مصدره الخادم. انتهاء الرخصة يمنع معاملات جديدة ويسمح قراءة/تصدير/نسخ واستعادة وإغلاق وردية. تحقق داخل بداية المعاملة، لا قطع commit.
backup API لـSQLite مع integrity_check وschema؛ نسخة أمان قبل الاستعادة. الرخصة وختم الوقت خارج قاعدة النشاط فلا يرجعان باستعادتها. لا حماية مطلقة ضد مدير نظام محلي؛ قاعدة البيانات غير مشفرة بهذا الإصدار.
استعادة المدير الوحيد بتحدي هب موقّع وإثبات ملكية متطلب إصدار غير منفذ. لا كلمة خلفية. المدير يغير كلمات الموظفين المؤقتة؛ PIN غير منفذ.
