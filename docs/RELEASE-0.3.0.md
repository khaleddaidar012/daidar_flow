# إصدار 0.3.0 — إعداد أول تشغيل

معالج للمدير: الموردون ← المنتجات ← الموظفون ← أنت جاهز الآن ← ابدأ الشغل.

- حفظ والتالي يحفظ بيانات حقيقية في SQLite، مع حفظ وإضافة آخر لإدخال أكثر من سجل.
- الرجوع ظاهر أعلى النموذج ولا يمسح السجلات المحفوظة. يمكن متابعة البيانات الموجودة دون تكرارها.
- المنتج يحتاج الاسم وسعر البيع والمخزون؛ التفاصيل الإضافية اختيارية.
- الموظف له دور وكلمة مرور مؤقتة تتغير عند أول دخول. يمكن للمالك اختيار العمل بحساب المدير فقط صراحة.
- التقدم محفوظ عند إغلاق التطبيق. بعد ابدأ الشغل لا يظهر المعالج مجددًا، وتبقى إدارة البيانات متاحة من أقسام البرنامج.
- عند ترقية تثبيت قديم يظهر المعالج مرة واحدة للمدير، ويستخدم الموردين والمنتجات والموظفين الموجودين بالفعل.
- المعالج للمدير ذي الرخصة السارية؛ انتهاء الرخصة لا يحجب القراءة والتصدير والنسخ الاحتياطي.
- لا تغيير في مخطط قاعدة البيانات: الحالة ضمن settings الموجودة وتدخل في النسخ الاحتياطية.

## التحقق

نجح TypeScript و11 مجموعة اختبارات، بينها الترتيب والصلاحيات وحفظ الرجوع وإعادة الفتح وإكمال المعالج دون موظف وهمي.
نجح اختبار Electron الفعلي باستخدام ملف بيانات اختبار مستقل: مورد، منتج، رجوع، موظف، جاهز، ابدأ، ثم إعادة تحميل تؤكد اختفاء المعالج. يستمر الاختبار بالمشتريات والباركود والبيع.
